# v5 真实试跑基线

`original/C0001.py`～`C0006.py` 是用户提供的 trial-joint-v5 原始源码，按原始字节归档；SHA256 见 provenance.json。不得改写成新搜索成绩。

`C0003_manual.py` 是人工修订对照，借用 C0003 的随机半径覆盖构造方式，修正完整归属操作，明确采用减巢、迁巢、搬移/交换的 1:2 尝试顺序。由候选显式调用结构原语、网络评价和 remember，不是框架隐藏优化，也不是新的 LLM 发现。原始 C0003 的旧分数不能直接当作新工具下的成绩。

模型只在服务器可用。先按 README 验收权重，再在相同冷缓存与工作预算下运行 benchmark；基准不调用 LLM。固定种子不保证墙钟预算下结果完全一致。
